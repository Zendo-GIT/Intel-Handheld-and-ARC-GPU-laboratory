# Code of conduct

Be respectful, precise, and evidence-driven. Assume good faith, distinguish measurements from impressions, and avoid pressuring others to test unsafe or irreversible changes.

Harassment, personal attacks, discriminatory conduct, fabricated results, unauthorized redistribution of protected files, and instructions intended to defeat anti-cheat protections are not accepted.

Project maintainers may edit or remove content that violates these boundaries and may restrict participation when necessary to protect users or the project.
