CLAWLAB VRR INSTALL DIAGNOSTICS 1.0.1
=====================================

This support collector is read-only. It does not install or restore a VRR
profile and does not change the display, Intel driver, registry or tasks.

For the most complete report, copy these three files into the fully extracted
MSI-Claw-8-Intel-VRR-Range-Fix-2.0.2 folder, then run:

  COLLECT_VRR_INSTALL_DIAGNOSTICS.bat

The tool creates a timestamped ZIP on the Windows desktop. Review its JSON
before public sharing because it contains hardware and local path information.
