# Security policy

## Reporting a vulnerability

Use GitHub private security advisories for a flaw that could:

- modify an unintended file or path;
- accept an unknown executable build;
- fail to restore a verified vanilla file;
- return network access while a protected executable remains modified;
- expose private local data;
- package a prohibited binary or archive.

Ordinary compatibility and installation bugs may use the game-specific issue form.

Do not attach proprietary game files, executable backups, save data, account data, crash dumps, private ETL files, anti-cheat bypasses, or bypass links.

## Anti-cheat boundary

The repository does not accept requests to evade anti-cheat detection, enable online use of a modified protected executable, or distribute a bypass. The Inazuma project is offline-only and its fail-closed network/restoration behavior is considered security-sensitive.
