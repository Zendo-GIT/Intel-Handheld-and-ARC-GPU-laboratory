MSI CLAW INTEL VRR RANGE FIX - CHANGELOG
========================================

2.1.2 - 2026-08-16
------------------
- Supports the exact A1M / Claw 7 AI+ 128-byte physical EDID when Windows adds
  one entirely zero-filled 128-byte buffer. Unknown/non-zero tails stay refused.
- Confirms this representation in Core Ultra 5 and Core Ultra 7 A1M diagnostics.
- Adds atomic schema-4 stable panel identity to LFC component 2.0.4 so a safe
  Intel-driver monitor-instance rename no longer creates a recovery loop.
- Fixes Windows PowerShell schema-3 restore by replacing the invalid null
  atomic-backup argument with a verified same-directory rollback path.
- Applies LFC only when exact 30-120 or 48-120 driver readback is present;
  every other range is refused before backup, task or flag changes.
- Splits core VRR/LFC health from optional desktop-helper health.
- Adds DIAGNOSTICS\EXPORT_STATUS_REPORT.bat and explicit failed-query reporting.
- Never manually delete %%LOCALAPPDATA%%\ClawLab; use RECOVERY instead.
- Detects lost LFC backups with disabled flags and provides a separate guarded
  EMERGENCY factory-default action only for that unrecoverable-original case.

2.1.1 - 2026-08-16
------------------
- Starts the Cursor Refresh Helper before the slow Intel stabilization stage.
- Extends the mouse-activity tail from 500 ms to 1.5 seconds.
- Enters tool-independent deep idle during controller/game use: the helper
  stops animation, releases its 1 ms timer request, trims its own working set,
  and wakes on the next visible raw-mouse packet.
- Adds HEALTHY / INITIALIZING / ATTENTION_REQUIRED status and Intel driver-change
  verification.
- Reports VERSION_MISMATCH when CHECK_STATUS 2.1.1 finds an older installed helper.
- Adds an interactive historical-CRU preflight to both installers.
- Reorganizes the ZIP into root install/status files, RECOVERY, EMERGENCY,
  DIAGNOSTICS, scripts and SOURCE.
- Keeps the 2.0.3 Intel LFC correction unchanged.

2.1.0 - 2026-08-16
------------------
- Adds the event-driven Cursor Refresh Helper validated on the reference Claw.
- Raw mouse movement animates a nearly transparent 2x2 WPF/DWM surface in the
  extreme lower-right corner so the desktop rises to 120 Hz.
- Stops 500 ms after mouse input and has no active animation timer at idle.
- Suppresses animation for hidden cursors and supports Xbox Full Screen Experience.
- Publishes rebuildable C# source and integrates install, sign-in launch,
  integrity status and complete restore cleanup.
- Does not change the existing Intel LFC fix.
- Removes per-mouse-packet native allocations; the optimized helper no longer
  causes the cursor micro-stutter reproduced during prototype testing.
- Adds exact TMA2027 / TL070FVXS02-0 Claw A1M support with a pinned 128-byte
  EDID, one-block 30-120 generator and offline checksum/hash test.
- Keeps A1M real-device behavior explicitly community-validation pending.
- Fixes one-shot sign-in completion: LFC waits for the direct VRR child but not
  for the resident Cursor Refresh Helper launched by that child.
- Requires reset-all.exe from the current official CRU release plus a restart
  whenever CRU was ever used on the same Windows installation.

2.0.3 - 2026-08-15
------------------
- Supports valid systems where Intel Graphics Software and its machine Run
  entry are both absent.
- Saves that absence directly instead of requiring a nonexistent canonical
  executable.
- Preserves an external Intel startup entry if one appears after installation.
- Saves elevated failures to last-error.txt and shows them in the parent
  console.

2.0.2 - 2026-08-15
------------------
- Removes both 144 Hz installers and the temporary confirmation task.
- Keeps legacy 144 Hz signatures only so older installations can be detected
  and restored safely to 120 Hz.
- Refuses persistence for retired 144 Hz profiles.
- Leaves only corrected 30-120 and official Intel/MSI 48-120 as public choices.
- Makes missing legacy LFC folders and files safe during restore.
- Accepts an originally absent Intel Graphics Software Run entry and restores
  it as absent instead of leaving a first install stuck.

2.0.1 - 2026-08-15
------------------
- Integrates the community-validated Intel LFC x2 correction into all four
  installers. The directly tested combination uses EXCELLENT, the exact
  30-120 Hz EDID override, and disables both Intel low- and high-FPS solutions;
  every other profile receives the same guarded operation with exact checks.
- Replaces the 30-120-specific companion with one profile-aware LFC module and
  binds its backup to the selected managed mode.
- Requires both guarded 144 Hz trials to verify their range and shared LFC flags
  before observation. Rejection restores original LFC and VRR state together.
- Adds repository/build checks that reject any installer missing the shared fix.
- Direct behavior is real-hardware validated at 30-120 Hz; both 144 Hz profiles
  retain experimental status.
- Documents that LFC below the selected 30 or 48 Hz floor is unavailable while
  the correction is active.

2.0.0 - 2026-08-15
------------------
- Integrates the community-validated Intel LFC x2 correction into the guarded
  30-120 Hz installer. The tested combination uses EXCELLENT, the exact
  30-120 Hz EDID override, and disables both Intel low- and high-FPS solutions.
- Adds an independent backup/readback/restore path for both original flags and
  a windowless one-shot sign-in reapply with no continuous watchdog.
- Restricts the correction to 30-120 Hz. Official 48-120 and optional 48-144
  receive no unverified LFC claim.
- Documents that LFC below 30 FPS is unavailable while the correction is active.
- Organizes four public profiles: default corrected 30-120, official Intel/MSI
  48-120, guarded 48-144, and guarded 30-144.
- Adds a one-time 144 Hz failsafe: 20 seconds of verified observation followed
  by Yes to keep, or No/close/30-second timeout to restore 120 Hz and restart.
- Exposes 30-144 only through the guarded flow and discloses the visible
  flicker observed on the reference panel.

1.0.3 - 2026-08-15
------------------
- Adds safe Intel Graphics Software update detection. A replaced executable is
  trusted only after fresh Windows Authenticode validation confirms Intel,
  the canonical path and original -s command, followed by stable SHA-256
  verification and an atomic identity-record update.
- Migrates older saved identities to schema 2 with signer thumbprint, file
  version and SHA-256.
- Retains the 48-144 Hz installer as a clearly disclosed experimental panel
  overclock. Fixed 144 Hz was stable on tested hardware, but VRR at 144 Hz or
  throughout the advertised range is not guaranteed.
- Keeps the visibly flickering 30-144 profile unavailable and recovery-only,
  with an explicit rejected-profile status for safe restoration.

1.0.2 - 2026-08-15
------------------
- Adds an optional 48-144 Hz DisplayID profile after guarded hardware testing
  confirmed a stable 1920x1200 144 Hz mode and EXCELLENT / 48-144 Hz readback.
- Withholds 30-144 Hz after visible flicker on the reference panel.
- Adds a read-only display/EDID collector for unsupported Claw models such as
  A1M. It is diagnostics only and does not apply a display fix.
- Adds verified fixed-refresh persistence for 48-144 after community testing
  found Windows returning to 120 Hz after restart.
- Adds startup-safe SHA-256 verification of the Intel Graphics Software
  executable previously validated with Authenticode during installation.
- Adds a mandatory managed-mode interlock that refuses every profile change
  until RESTORE_ORIGINAL_VRR.bat completes. Same-mode repair remains allowed.
- Adds FACTORY_RESET_CLAWLAB_VRR.bat for mixed or damaged ClawLab VRR state
  when the saved original Arc Sync profile cannot be used.

1.0.1 - 2026-08-15
------------------
- Adds persistent EXCELLENT / 48-120 Hz reapply after restart validation showed
  Intel restoring RECOMMENDED / 60-120 Hz during driver startup.
- Adds a windowless current-user task that waits for the Intel display API,
  applies and verifies the profile, then starts Intel Graphics Software.
- Adds exact backup and restoration of Intel Graphics Software's verified,
  Intel-signed machine-wide startup entry to guarantee launch order.
- Adds task, startup-order and last-run status reporting.

1.0.0 - 2026-08-14
------------------
- Targets compatible Claw 8 AI+ and Claw 8 EX AI+ configurations through exact
  panel and EDID validation rather than model-name assumptions.
- Adds direct Intel Arc Sync status reporting.
- Adds verified official EXCELLENT / 48-120 Hz mode.
- Adds an optional experimental 30-120 Hz EDID override for the exact validated
  CSW0801 / PN8007QB1-2 panel and EDID.
- Adds original-profile backup, verified restore and Safe Mode emergency EDID
  removal.
- Adds a user-confirmed PC restart prompt after every change.
