MSI CLAW 8 AI+ / 8 EX AI+ VRR RANGE FIX - CHANGELOG
====================================================

1.0.3 - 2026-08-15
------------------
- Adds safe Intel Graphics Software update detection. A replaced executable is
  trusted only after fresh Windows Authenticode validation confirms Intel,
  the canonical path and original -s command, followed by stable SHA-256
  verification and an atomic identity-record update.
- Migrates older saved identities to schema 2 with signer thumbprint, file
  version and SHA-256.
- Retains the 48-144 Hz installer as a clearly disclosed experimental panel
  overclock. Fixed 144 Hz was stable on tested hardware, but VRR at 144 Hz or
  throughout the advertised range is not guaranteed.
- Keeps the visibly flickering 30-144 profile unavailable and recovery-only,
  with an explicit rejected-profile status for safe restoration.

1.0.2 - 2026-08-15
------------------
- Adds an optional 48-144 Hz DisplayID profile after guarded hardware testing
  confirmed a stable 1920x1200 144 Hz mode and EXCELLENT / 48-144 Hz readback.
- Withholds 30-144 Hz after visible flicker on the reference panel.
- Adds a read-only display/EDID collector for unsupported Claw models such as
  A1M. It is diagnostics only and does not apply a display fix.
- Adds verified fixed-refresh persistence for 48-144 after community testing
  found Windows returning to 120 Hz after restart.
- Adds startup-safe SHA-256 verification of the Intel Graphics Software
  executable previously validated with Authenticode during installation.
- Adds a mandatory managed-mode interlock that refuses every profile change
  until RESTORE_ORIGINAL_VRR.bat completes. Same-mode repair remains allowed.
- Adds FACTORY_RESET_CLAWLAB_VRR.bat for mixed or damaged ClawLab VRR state
  when the saved original Arc Sync profile cannot be used.

1.0.1 - 2026-08-15
------------------
- Adds persistent EXCELLENT / 48-120 Hz reapply after restart validation showed
  Intel restoring RECOMMENDED / 60-120 Hz during driver startup.
- Adds a windowless current-user task that waits for the Intel display API,
  applies and verifies the profile, then starts Intel Graphics Software.
- Adds exact backup and restoration of Intel Graphics Software's verified,
  Intel-signed machine-wide startup entry to guarantee launch order.
- Adds task, startup-order and last-run status reporting.

1.0.0 - 2026-08-14
------------------
- Targets compatible Claw 8 AI+ and Claw 8 EX AI+ configurations through exact
  panel and EDID validation rather than model-name assumptions.
- Adds direct Intel Arc Sync status reporting.
- Adds verified official EXCELLENT / 48-120 Hz mode.
- Adds an optional experimental 30-120 Hz EDID override for the exact validated
  CSW0801 / PN8007QB1-2 panel and EDID.
- Adds original-profile backup, verified restore and Safe Mode emergency EDID
  removal.
- Adds a user-confirmed PC restart prompt after every change.
