TITLE
Intel Arc Water Glitch Fix - Mesh Shader Fallback

VERSION
1.0.0

ONE-LINE SUMMARY
Fixes the flashing polygon and square water corruption on affected Intel Arc GPUs by forcing JWE3 1.4.2.0 to use its built-in VS/SM60 rendering path.

CATEGORY
Visuals

SUGGESTED TAGS
Bug Fixes, Graphics, Intel Arc, Steam

DESCRIPTION

Fixes the severe water corruption seen on affected Intel Arc graphics drivers,
where large flashing polygons, squares or triangles cover lakes and expose the
terrain below.

This is not a texture replacement. Jurassic World Evolution 3 ships with both
a classic vertex-shader / SM60 path and a mesh-shader / SM65 path. On the tested
Intel Arc driver, the corruption occurs on the mesh-shader path. This fix makes
JWE3 report mesh shaders as unavailable internally, causing the game to select
its existing classic rendering path instead.

CONFIRMED TEST SYSTEM

- MSI Claw 8 AI+ Polar Tempest
- Intel Core Ultra 7 258V
- Intel Arc 140V
- 32 GB RAM
- Intel Graphics driver 32.0.101.8864
- Jurassic World Evolution 3 1.4.2.0 (Steam)

The water corruption was eliminated in the same save and viewing location.
Results on other Arc GPUs or driver versions are possible but have not yet been
validated, so please report your GPU, driver and game version in the comments.

REQUIREMENTS

- Windows Steam version of Jurassic World Evolution 3
- JWE3.exe version 1.4.2.0 with the exact supported SHA-256
- Manual installation; this is not a Vortex package

INSTALLATION

1. Close Jurassic World Evolution 3 completely.
2. Extract the downloaded ZIP to a normal folder.
3. Double-click INSTALL_FIX.bat.
4. A successful result displays FIX_INSTALLED.
5. Launch the game normally through Steam.

The installer detects registered Steam libraries automatically. It refuses an
unknown executable, an unsupported game update, or unexpected bytes.

UNINSTALLATION

Close the game and double-click UNINSTALL_FIX.bat. The byte-identical original
backup is restored and verified. Steam's Verify integrity feature can also
restore JWE3.exe.

TECHNICAL DETAILS

Supported original SHA-256:
04FA75D84683DE73AAFF7C0D5C28D8FDC5B4E900E5968022995CF84039F0A79F

Patched SHA-256:
3A172D9261075017974897A2F4EB89F16232B5E5D711B2EA77A524394BD7FAA8

At file offset 0x1CB666D, JWE3 1.4.2.0 derives its internal mesh-shader support
flag from the D3D12 mesh shader tier using "setge al". The fix replaces that
three-byte instruction with "xor eax,eax; nop". The following original
instruction stores zero in the capability flag, so the engine creates and uses
its classic VS/SM60 pipeline.

KNOWN LIMITATIONS

- Release 1.0.0 supports only JWE3 1.4.2.0.
- A game update or Steam verification may remove the patch.
- Rendering performance can differ because a different built-in path is used.
- No FPS improvement is claimed; this release targets the visual corruption.
- Alt-Tab-related stutter is separate and is not fixed here.

TROUBLESHOOTING

If the installer says UNSUPPORTED_GAME_VERSION_NO_CHANGES_ALLOWED, do not force
the patch. Post the displayed SHA-256 and your JWE3 file version. A new game
version requires a newly analysed release.

If Steam is installed in an unusual location and automatic detection fails,
follow the manual -GameExe command shown in README.txt.
