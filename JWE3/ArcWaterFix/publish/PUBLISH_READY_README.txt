JWE3 INTEL ARC WATER GLITCH FIX - PUBLICATION BUNDLE
====================================================

This folder is split into two independent publication targets.

1. GitHub-Repository

   This is the complete source repository. It contains the public installer,
   uninstaller, documentation, MIT license, contribution and security policies,
   GitHub issue templates, pull-request template, validation workflow and a
   reproducible Nexus release builder.

   Start with:
     GitHub-Repository\README.md
     GitHub-Repository\docs\REPOSITORY_SETUP.md

2. Nexus-Mods

   This contains the exact ZIP to upload, its SHA-256, the page description,
   main-file description, upload checklist and available screenshots.

   Upload only:
     JWE3-Intel-Arc-Water-Glitch-Fix-1.0.0.zip

   Do not upload the whole publication bundle as the Nexus main file.

IMPORTANT

- No JWE3.exe or proprietary game asset is present in the ZIP or repository.
- The Nexus ZIP contains no nested archive.
- The release is manual-installation only, not Vortex-compatible.
- The code was developed with OpenAI Codex assistance. Do not enter it in the
  optional Nexus Mods 25th Anniversary Mod Drive, whose August-September 2026
