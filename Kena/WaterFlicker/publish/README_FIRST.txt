KENA INTEL ARC WATER FLASH FIX - PUBLICATION FILES
==================================================

Nexus Mods
----------

Upload only the finished ZIP from the Nexus-Mods folder. Use the accompanying
description and checklist when creating the page.

GitHub
------

The GitHub-Repository folder is a complete public-repository source tree. It
contains the validated PAK, English documentation, MIT-licensed tooling, and a
release builder.

Important
---------

The fix is validated for Steam build 10345375 on Intel Arc 140V with driver
32.0.101.8864. Flash elimination was observed on MI_WaterClean_Shallow; the
release applies the same verified scalar correction to all 31 compatible UIWS
surface instances. Do not claim a complete location-by-location playthrough or
support for other builds without additional real-hardware validation.
