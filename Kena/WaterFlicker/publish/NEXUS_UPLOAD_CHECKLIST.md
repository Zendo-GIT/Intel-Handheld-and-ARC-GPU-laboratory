# Nexus Mods upload checklist

- Upload only `Kena-Intel-Arc-Water-Flash-Fix-1.0.0.zip` as the main file.
- Use `Kena Intel Arc Water Flash Fix` as the mod title.
- Use version `1.0.0`.
- Paste `NEXUS_DESCRIPTION.md` into the description editor.
- Main-file description: `Native DX12 Intel Arc water-flash fix. Data-only PAK; manual installation.`
- Mark installation as manual unless the selected mod manager is verified with
  the game-relative `Kena/Content/Paks/~Mods` structure.
- Do not upload the entire publication workspace as the main file.
- Keep the release SHA-256 beside the uploaded archive for verification.
- State the Steam build and Intel driver used for validation.
- Do not claim support for untested water materials, builds, GPUs, or drivers.
