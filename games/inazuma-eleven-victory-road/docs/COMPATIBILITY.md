# Compatibility

## Validated

- INAZUMA ELEVEN: Victory Road for Steam
- Steam AppID `2799860`
- Steam build `24370575`
- vanilla `nie.exe` SHA-256 `B1FA04EA365868E5C8933ACA393366F82D0D446187E2187F2737DC4FA2ACD40C`
- MSI Claw 8 AI+ Polar Tempest
- Intel Core Ultra 7 258V / Intel Arc 140V
- Intel Graphics driver `32.0.101.8864`
- Windows 11

## Explicitly incompatible

- Easy Anti-Cheat active;
- online play or online game services;
- any `nie.exe` whose size or SHA-256 differs from the supported build;
- another executable patch that touches the supported file;
- a game update until the new executable has been analyzed and explicitly supported.

## Unverified

- other MSI Claw models;
- other Intel, AMD, or NVIDIA GPUs;
- other Intel graphics drivers;
- non-Steam storefronts;
- Windows versions other than the reference environment;
- interaction with unrelated offline-only mods.

The installer rejects an unsupported build rather than attempting a pattern-only patch.
